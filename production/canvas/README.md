# Canvas

## Fishman Island Canvas

Open `Fishman Island.canvas` in Obsidian.

The canvas maps the current Fishman Island rewrite across four layers:

- historical liberation
- present political control
- character conflict
- Gem systems and story consequences

The nodes link directly to authoritative files in `characters/`, `systems/`, `lore/`, and `story/`.

> [!tip]
> If Obsidian opens the canvas at an odd zoom level, use **Zoom to fit** once. The map is deliberately spread out so character cards and edge labels do not pile on top of one another.
