# Black Maria: Canon Audit

## Canon baseline

Canon Black Maria is a Tobi Roppo member with an Ancient spider Zoan and strong jorogumo/yukaku-like associations.

## What canon appears to be doing

Canon uses spider imagery, sexuality, Wano pleasure-quarter aesthetics, and yokai flavor.

Unless a source explicitly confirms authorial intent, this is **interpretation**, not a claim about Oda's private intention.

## Problems Peak Piece identifies

There is a temptation to make the Fruit literally Mythical jorogumo just to make the reference cleaner. If that changes nothing else, it is rarity inflation.

## Peak Piece response

Peak Piece lets setting, behavior, imagery, and presentation carry the jorogumo reference without upgrading the Fruit merely for taxonomy.

## Why this solution

A reference does not need to be printed on the power-system label to work.

## What we preserve

Spider identity, Wano/yokai texture, visual folklore connection.

## What we intentionally reject

Mythical inflation for literalism alone.

## Failure modes to watch

Any future Fruit-model change must solve an actual mechanical/story problem.
