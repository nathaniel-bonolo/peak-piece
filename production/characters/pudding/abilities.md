# Charlotte Pudding: Abilities

## Memo-Memo Fruit

Pudding can extract and manipulate memories.

Peak rule:

> **She relives extracted memories in first person.**

This makes memory work psychologically expensive.

## Single-person extraction

Working inside one person's memory network is normally manageable.

Pudding can move surprisingly deep because the associations ultimately belong to one coherent autobiography.

Depth alone is not the primary source of identity drift.

## Multi-person accumulation

The dangerous case is repeated work across multiple people.

This is especially severe when Pudding repeatedly searches for the same emotional category.

Example:

> fear of spiders from one person  
> → basement memory from another  
> → father's voice from a third  
> → daughter from a fourth

Her own brain begins wiring foreign associations together.

That creates:

- emotional residue
- behavioral bleed
- relationship bleed
- fear transfer
- autobiographical confusion
- identity drift

## Military use

Pudding can:

- extract fears
- extract tactical information
- preserve combat experience
- build sanitized training packages
- support interrogation
- preserve useful memories from dying soldiers
- identify psychological routes to surrender for high-value harvests

She is not an instant Professor X.

Extraction, curation, and installation take time.

Conflicting memory sets create noise.

## Orchard / harvest use

For a captured Charlotte prospect, Pudding can identify:

- what the person fears
- which fears are likely to produce high extraction yield
- what makes them feel helpless
- what is likely to make them surrender
- what may push them into incoherent **bruising**

Her job is not simply:

> find the most evil thing we can do

The empire wants a strong person to submit **without destroying the coherence that makes the soul valuable**.

See [[production/lore/factions/charlotte-orchard|The Orchard]] and [[production/systems/soul-system|Soul System]].

## Limits

Her own mind is the bottleneck.

The more people she carries at once, the less certain she becomes that a reaction, fear, habit, relationship, or memory belongs to her.

This can produce mundane symptoms as easily as dramatic ones.

## Cracker soldier templates

Pudding's memory work can provide **limited standardized tactical templates** to the soul-bearing biscuit soldiers.

The purpose is distributed autonomy, not arbitrary memory programming.

A limited template lets soldiers:

- hold formation
- recognize simple orders
- execute drills
- react locally

The manga does not need to describe this as "biscuit shell + soul substrate + memory template" in engineering language.

## Template mistakes

Memory-template work is repeatable enough to become routine.

That creates a human failure mode:

an expert who has done the process a thousand times can rush it.

The model scene remains [[production/lore/factions/small-moments/charlotte-family/backwards-salute-batch|Backwards Salute Batch]].

Do **not** reuse the salute gag every time Pudding needs an identity anchor.

It works because it is one old stupid mistake, not her universal character motif.
