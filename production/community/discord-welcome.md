# Discord Welcome

# Welcome to One Piece: Recharted

This is a collaborative **reimagining** of One Piece.

It is not limited to "fix post-timeskip mistakes and otherwise preserve canon."

Sometimes we repair. Sometimes we preserve. Sometimes we take ingredients canon already used well and ask what another version could become.

Before doing major writing, read the short foundation document:

https://github.com/nathaniel-bonolo/peak-piece/blob/main/production/FOUNDATIONS.md

Current foundational directions include meaningful Luffy progression, Devil's Hand Hordy, Brook's second-life/dead-promises arc, and the Poneglyph suppression architecture.

Those directions are **not immune to criticism**. Their execution can change. They are disclosed because nobody should contribute for weeks and only later discover what kind of rewrite this is.

If you want to **read the current story so far**, go to the GitHub repo and open the `story/` folder:

https://github.com/nathaniel-bonolo/peak-piece/tree/main/story

`story/` is the readable canonical version of Recharted.

Discord is where discussion happens: brainstorming, arguing about ideas, character rewrites, systems, arc planning, research, feedback, and deciding what should become canon.

**GitHub is the source of truth. Discord is the writers' room.**

Ideas can be discussed here first. Once we agree on them, they get added to the actual story, character, lore, or system files.

A new idea does not need to instantly prove it is better than finished canon before it is allowed to be explored. If it has real potential, let it cook; then compare the developed version.

You do not need to agree with every idea. If something does not make sense, question it.

Critique the idea, not the person.

**Question everything.**
