# Writers' Room Workflow

Peak Piece does **not** require every collaborator or reviewer to become a Git user.

## Easy drafting surfaces

Use whatever is practical for brainstorming, dialogue, scene drafts, research dumps, and fast discussion:

- chat / Discord
- shared Docs
- local notes
- Obsidian
- GitHub

Material written outside the repository is not automatically canon. Accepted material is integrated into the repository's authoritative files.

The historical Discord associated with the shared rewrite now belongs to the sibling **One Piece: Recharted** community. See [[production/community/discord-welcome|Recharted Discord]].

## Decision states

Substantial ideas can move through:

> **Draft → Contested → Converging → Locked**

### Draft

The direction is being built. Criticism is welcome, but do not pretend an unfinished pitch has already demonstrated finished execution.

### Contested

There is meaningful disagreement about direction, cost, or fit.

Contested does not mean "dead." The point is to develop the strongest version, not repeat the same one-paragraph argument forever.

### Converging

The direction broadly works. Remaining work is mostly implementation, continuity, or wording.

### Locked

The direction is authoritative until new evidence or a genuinely better replacement justifies reopening it.

Not every tiny scene needs a formal state or vote.

## Foundations are a separate layer

[[production/FOUNDATIONS|Foundations]] describe the adaptation itself.

They are not ordinary proposals.

Foundations can still be criticized in execution.

## Full project view

Use Obsidian when you want the folder hierarchy, backlinks, systems, character files, lore, and production bible.

Use [[prompts/AGENTPROMPT|Agent Prompt]] when you want a repository-capable AI to navigate the project conversationally. Use [[prompts/CONTRIBUTORPROMPT|Contributor Prompt]] when onboarding someone who is still deciding whether they fit as a writer, beta reader, artist, researcher, editor, designer, reviewer, or tooling contributor.

For a normal Git installation:

```bash
git clone https://github.com/nathaniel-bonolo/peak-piece.git
```

Then open the generated `peak-piece` folder as an Obsidian vault.

Do **not** tell somebody to use `gh repo clone` unless GitHub CLI is installed.

## Source of truth

> **GitHub is the filing cabinet. Obsidian is the full linked view. Other tools are drafting / discussion surfaces.**

GitHub remains useful because the project can grow into hundreds or thousands of linked files and benefits from exact structure, history, diffs, branches, and one authoritative current state.

## Variant divergence

Peak Piece and Recharted are examples of a healthy outcome when collaborators discover they want different adaptation premises.

Do not treat branching into variants as a creative failure or competition.

Preserve work, attribution, and useful cross-pollination when possible.
