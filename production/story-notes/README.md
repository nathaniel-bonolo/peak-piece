# Story Notes

This folder mirrors writer-only reasoning for material in `story/`.

The reader-facing file stays in `story/`.

The production material stays here.

Example:

```text
story/sagas/fishman-island/arcs/fishman-island/arc.md
production/story-notes/sagas/fishman-island/arcs/fishman-island/canon-audit.md
```

Writer-only material can include:

- canon audits
- tone tests
- scene seeds
- tactical breakdowns
- alternate routes
- spoiler-heavy reasoning

Do not require a reader to open this folder to understand the story.

> **The spreadsheet is ours. The audience gets the adventure.**
