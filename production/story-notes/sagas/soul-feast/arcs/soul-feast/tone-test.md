# Soul Feast Tone Test

Run this against actual chapters.

The design document is allowed to be ugly.

The chapter is not.

## Acceptance questions

### Can the scene be understood without the repo?

If a reader needs the system note to understand what happened, rewrite the scene.

### Do the characters still sound like themselves?

If two pages pass where everybody sounds like military analysts, rewrite.

Luffy can authorize a plan without explaining geopolitics.

Kaido can approve Queen's proposal without becoming Queen.

Linlin can understand an empire without talking like an economist.

### Did the tactical beat reveal character?

A system interaction should ideally reveal at least one of:

- personality
- assumption
- fear
- competence
- mistake
- relationship
- priority
- cost

If it only proves the author thought through the mechanics, ask whether it belongs on the page.

### Does every Fruit feel optimized?

If yes, something is wrong.

Ask whether:

- this user would actually think of the application
- someone around them would
- they care enough to implement it
- the institution has learned enough to standardize it
- a shortcut, bad habit, or personal preference would produce a messier result

### Did competence become omniscience?

Good plans should contain assumptions.

Some assumptions should fail.

Linlin's Hyena extraction is a model:

the move is rational from her information and still wrong.

### Is the weirdness still weird?

The reader should experience:

> Apoo turned the soundtrack into a weapon.

Not:

> acoustic resonance infrastructure achieved target threshold.

The first sentence is the story.

The second belongs here.

### Are there ordinary human moments?

War cannot be nothing but optimized systems colliding.

Use:

- jokes
- family habits
- panic
- pettiness
- food
- arguments
- exhaustion
- embarrassing mistakes
- stupid traditions
- affection

A backwards-saluting Biscuit Reserve batch belongs in the same empire as Final Service.

### Did an explanation arrive too early?

Some worldbuilding is better as a rewatch reward.

Wano's mirror restrictions can first read as another stupid Orochi law.

The reader does not need the Brulee explanation in the same scene.

## North star

> **The spreadsheet is ours. The audience gets the adventure.**
