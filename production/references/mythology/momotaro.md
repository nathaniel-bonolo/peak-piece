# Momotaro

Reference discussed by **CerezaVeneris**.

## Core story pattern

Momotaro travels to Onigashima accompanied by animal allies commonly represented as:

- monkey
- dog
- pheasant

Dango is part of the recruitment imagery.

Canon Wano deliberately uses this story as a major reference structure.
