# Jorogumo

Reference raised by **CerezaVeneris** while auditing [[production/characters/black-maria/overview|Black Maria]].

Reference:
https://yokai.com/jorougumo/

## Rewrite decision

Peak Piece does not need to make Black Maria's Fruit Mythical merely to make the reference literal.

The folklore can live in:

- character presentation
- spider imagery
- the yūkaku / brothel setting
- visual language

The reference should enrich the character without inflating the power system.
