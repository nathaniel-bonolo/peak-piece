# Templates

These templates are designed to work with Obsidian's built-in **Templates** core plugin, but they can also be copied manually.

## Setup in Obsidian

1. Enable **Templates** under Core Plugins.
2. Set the template folder location to `templates/`.
3. Create a new note in the correct project folder.
4. Insert the appropriate template.
5. Replace placeholder titles, aliases, tags, and links.

## Obsidian rules

- Prefer path-qualified links such as `[[production/characters/hordy/overview|Hordy Jones]]`.
- Add a `## Related` section so backlinks form deliberately.
- Keep `status` explicit.
- Use `canon: false` for proposals and unresolved concepts.
- When a proposal is accepted, edit the authoritative file instead of making an "accepted proposal" canon.
