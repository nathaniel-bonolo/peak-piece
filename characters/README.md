## Character folder pattern

Major characters usually use:

- `overview.md` — core identity, role, worldview
- `abilities.md` — mechanics and combat use
- `progression.md` — starting state, change, payoff
- `relationships.md` — important interpersonal dynamics

Only create the files a character actually needs.

Do not create empty bureaucracy for minor characters.

## Obsidian linking

Because many character folders contain an `overview.md`, always prefer path-qualified wikilinks:

- [[characters/hordy/overview|Hordy Jones]]
- [[characters/shirahoshi/overview|Shirahoshi]]
- [[characters/linlin/overview|Charlotte Linlin]]

Do not link to `[[overview]]`.

## Canon rule

Accepted character material belongs here.

Unresolved character redesigns belong in [[proposals/README|Proposals]] until their useful parts are merged into the authoritative character files.

## Canon audits

Every developed character folder keeps `canon-audit.md` beside the authoritative character files. It records what canon does, what we think its function is, what Peak Piece changes, why, what survives, what is intentionally rejected, failure modes, and references.

Do not create a separate audit tree. See [[references/canon/source-policy|Canon Audit Source Policy]].
