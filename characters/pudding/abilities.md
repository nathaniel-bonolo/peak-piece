# Charlotte Pudding: Abilities

## Memo-Memo Fruit

Pudding can extract and manipulate memories.

Peak rule:

> **She relives extracted memories in first person.**

This makes memory work psychologically expensive.

## Military use

Pudding can:

- extract fears
- extract tactical information
- preserve combat experience
- build sanitized training packages
- support interrogation
- preserve useful memories from dying soldiers

She is not an instant Professor X.

Extraction, curation, and installation take time.

Conflicting memory sets create noise.

## Limits

Her own mind is the bottleneck.

The more she extracts, the less certain she becomes that a reaction, fear, habit, relationship, or memory belongs to her.

## Cracker soldier templates

Pudding's memory work can provide **limited standardized tactical templates** to the soul-bearing biscuit soldiers. The purpose is distributed autonomy, not arbitrary memory programming.

At canon-like army scale, Cracker cannot plausibly micromanage every limb of thousands of soldiers without his hidden superpower becoming impossible parallel cognition. A limited template lets soldiers hold formation, recognize simple orders, execute drills, and react locally.

The manga does not need to describe this as "biscuit shell + soul substrate + memory template" in engineering language. It only needs to establish that the soldiers can operate independently and that the autonomy comes from soul/memory machinery already introduced.

## Template mistakes

Memory-template work is repeatable enough to become routine.

That creates a human failure mode:

an expert who has done the process a thousand times can rush it.

Peak Piece should allow harmless legacy defects rather than treating Charlotte production as flawless automation.

The model scene is [[lore/factions/small-moments/charlotte-family/backwards-salute-batch|Backwards Salute Batch]].

The mistake does not make the soldiers tactically useless.

It creates one stupid behavior that costs more to repair than to tolerate.
