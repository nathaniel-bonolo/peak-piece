# Charlotte Katakuri: Abilities

Status: Draft

## Mochi

Mochi is deformable battlefield control.

Useful applications include:

- adhesion
- restraint
- impact absorption
- catching projectiles
- catching allies
- temporary seals
- controlling movement
- deformable cover

It is edible, but using it as normal food production is economically inefficient.
