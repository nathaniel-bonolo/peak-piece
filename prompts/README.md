# Prompts

The repository is the source of truth. These prompts are conversational entry points over it.

- [[prompts/AGENTPROMPT|Agent Prompt]]: understand Peak Piece and work with the production bible.
- [[prompts/CREATORPROMPT|Creator Evaluation Prompt]]: skeptical cold-entry evaluation for creators, reviewers, streamers, essayists, and serious fans.
- [[prompts/CONTRIBUTORPROMPT|Contributor Onboarding Prompt]]: interactive fit and contribution mapping for writers, beta readers, artists, researchers, editors, designers, tooling contributors, and detailed readers.

Using these prompts does not require using AI to create contributions. They are primarily navigation and ingestion tools.
