# Systems

This directory contains rules that apply across the story.

A system file should answer:

- What is the core rule?
- What can it do?
- What can it not do?
- What does it cost?
- What second-order effects follow from it?
- How has the world adapted to it?

Do not use system files as dumping grounds for every scene where the system appears.
