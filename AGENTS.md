# Peak Piece Agent Guide

Before evaluating, summarizing, modifying, or answering project-specific questions about Peak Piece, read the project documents that establish intent and status.

Start with:

1. `README.md`
2. `production/FOUNDATIONS.md`
3. `production/DECISION-STATUS.md`
4. `production/WRITING-PHILOSOPHY.md`
5. `production/REVIEW-PROTOCOL.md`
6. the relevant character, story, lore, system, or proposal files

Treat repository status explicitly. Do not collapse these into one category:

- One Piece canon
- Peak Piece foundational / locked material
- draft implementation
- contested extensions
- active proposals
- rejected / superseded material

Peak Piece is a **reimagining**, not a fidelity-first repair project. Canon material may be deliberately replaced even when the project understands and respects what canon was doing.

Evaluate a direction according to its stated function, consequences, gains, losses, and execution rather than assuming similarity to canon is itself the goal.

If a user makes a factual claim about Peak Piece, verify it against the current repository when possible.
